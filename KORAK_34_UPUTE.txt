KORAK 34 - React Router i useParams

1. Raspakirajte ZIP u mapu projekta.
2. U terminalu pokrenite: npm install
3. Pokrenite: npm run dev
4. Provjerite navigaciju kroz sve stranice.
5. Otvorite motocikl i provjerite URL /vozila/ID, povratak na popis i osvježavanje stranice.
6. Provjerite uređivanje i brisanje motocikla, podatke i šest tema.

Napomena: package-lock.json se regenerira tijekom npm install zbog nove ovisnosti react-router-dom.
Ovdje nije bilo moguće instalirati pakete i provesti produkcijski build.
